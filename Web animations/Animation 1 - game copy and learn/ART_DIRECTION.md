# Ruins Python Character Art

All future imagery must preserve these three friendly snake characters and the established polished adventure-game rendering:

- Emerald Python: vivid emerald body, yellow-green circular markings, pale yellow belly, large rounded green eyes, soft closed-mouth smile.
- Rust Viper: rust-orange and cream bands, rounded amber eyes, friendly compact muzzle, no visible fangs.
- Moon Boa: pale moon-blue armored scales, blue eyes, rounded pale muzzle, gentle expression.

Use the same rounded facial proportions, large warm eyes, and polished scale depth as `assets/intro-cover-v2.png`, `assets/level2-cover.png`, `assets/level3-cover-v2.png`, `assets/level4-cover-v2.png`, `assets/level5-cover.png`, and `assets/level-complete-cover.png`. Never use narrow angry eyes, aggression, horror styling, duplicate heads, or additional snakes. Mice should be clearly visible, friendly, and consistent with the field-guide SVGs.
